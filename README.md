# poskinson — Discord-бот

Грубоватый бот-собеседник для Майнкрафт-сервера на бесплатных нейросетях. Подробности по версиям — `CHANGELOG.md`, идеи — `IDEAS.md`.

## Запуск на ПК (Linux)
```
cd ~/Projects/discord-bot
.venv/bin/python bot.py          # вручную
systemctl --user restart poskinson   # как служба
journalctl --user -u poskinson -f    # логи
```
Ключи лежат в `.env` (шаблон — `env.example` в скилле `discord-bot`). Минимум: `DISCORD_TOKEN` и `GROQ_API_KEY`.

## Перенос на телефон (Termux)

Бот — обычный Python-скрипт: зависимости `discord.py` и `httpx`, база — один файл `memory.db`. Так что на телефоне он запускается без проблем.

**Главное правило: бот должен работать только в ОДНОМ месте.** Если запущены и ПК-версия, и телефонная, с одним токеном, каждое сообщение получит два ответа.

### 1. На ПК: собрать zip
```
systemctl --user stop poskinson      # остановить ПК-версию
~/Projects/discord-bot/tools/make-phone-zip.sh
```
Получится `~/poskinson-phone.zip`: код, `.env` с ключами и свежая копия памяти (`memory.db`). Без `.venv`, логов и бэкапов. **Внутри ключи**, поэтому не пересылай архив никому и удали его после переноса. Передать на телефон можно кабелем, через Localsend/Syncthing или «Поделиться» в свой облачный диск. Через открытые мессенджеры лучше не надо.

### 2. На телефоне: поставить Termux
Ставь Termux **из F-Droid** (версия из Google Play устарела и не обновляется). Открой его и выполни:
```
termux-setup-storage                 # разрешить доступ к файлам
pkg update && pkg upgrade
pkg install python git tmux unzip
```

### 3. Распаковать и поставить зависимости
Допустим, zip лежит в «Загрузках»:
```
cd ~
unzip ~/storage/downloads/poskinson-phone.zip
cd discord-bot
pip install discord.py==2.7.1 httpx==0.28.1 tzdata
```
Если `pip` ругается на сборку `aiohttp`, `multidict` или `yarl`, сделай `pkg install clang make libffi openssl` и повтори.

`tzdata` нужен, потому что в Termux нет системной базы часовых поясов, без него `zoneinfo` падает при старте.

`ddgs` (веб-поиск) на Termux ставить **не нужно**: он тянет тяжёлые зависимости. Без него только не работает инструмент поиска, а остальное живёт, ошибка в боте перехватывается.

После переноса удали zip: `rm ~/storage/downloads/poskinson-phone.zip`.

### 4. Запуск
Сначала проверь вручную:
```
cd ~/discord-bot
python bot.py
```
Должно появиться, что бот зашёл в Discord. Остановка — `Ctrl+C`.

Чтобы работал в фоне и не умирал при закрытии Termux:
```
termux-wake-lock                     # не давать телефону усыпить процесс
tmux new -s bot                      # сессия tmux
python bot.py
# выйти из tmux, оставив бота работать: Ctrl+B, потом D
# вернуться: tmux attach -t bot
```
Автоперезапуск при падении (в tmux):
```
while true; do python bot.py; sleep 15; done
```

### 5. Чтобы Android не убивал Termux
- Настройки → Приложения → Termux → Батарея → **Без ограничений**.
- Закрепи Termux в списке недавних приложений (замок/«закрепить») и не смахивай его.
- В шторке Termux включи **Acquire wakelock** (или команда `termux-wake-lock`).
- На Xiaomi/Samsung/Huawei есть ещё свои «оптимизаторы», отключи для Termux и их.

### 6. Нюансы
- **Discord в РФ заблокирован**, поэтому телефону нужен VPN или прокси, как и на ПК. Без него бот не подключится.
- Бот нужно держать на зарядке и Wi-Fi: с мобильным интернетом и в режиме экономии он засыпает.
- Бэкапы памяти бот делает сам каждую ночь в `backups/` (на телефоне это `~/discord-bot/backups/`).
- Путь в коде относительный (`config.HERE`), так что переименовывать и перемещать папку можно без правок.
- Обновление: на ПК правишь код → снова `make-phone-zip.sh` → распаковка поверх. **Но `memory.db` в архиве затрёт память на телефоне**, поэтому при обновлении распаковывай без неё: `unzip -o ... -x '*/memory.db'`.

### Вернуть бота на ПК
На телефоне останови бота, скопируй `memory.db` на ПК в `~/Projects/discord-bot/` (так сохранится память), затем `systemctl --user start poskinson`.
