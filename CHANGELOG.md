# История версий poskinson

Все версии пока — бета: бот обкатывается, поведение и команды ещё меняются.

## 3.10.1-beta — 2026-10-05
- Третий ключ Groq (`groq3`): у каждой модели Groq очередь ключ 1 → 2 → 3; в мониторе лимит 600 тыс. на модель.

## 3.10.0-beta — 2026-10-04
- Крупный фон — через OpenRouter (новая роль `bulk`: Nemotron Ultra 550B → Nemotron Super → Qwen, бесплатные):
  у него лимит на запросы (~50/день), а не на токены, и огромное окно — Groq остаётся под болтовню.
  - чтение истории: весь канал одним запросом (до 120 тыс. символов) вместо 3–4 кусков через Groq;
  - карточки людей: пачками по 6 в одном запросе (JSON), остаток — по одной через Groq, как раньше;
    после чтения истории — один раз за сервер, а не после каждого канала;
  - база знаний сервера — сначала через OpenRouter.
  Свой дневной лимит `bulk` = 25 запросов (остальное — резерв болтовни). Не вышло — всё как раньше через Groq.
- OpenRouter — без «размышлений» (иначе модели тратили весь ответ на рассуждения или отвечали пусто).
- Крупным фоновым запросам — своё время ожидания (5 минут), болтовне — прежнее.
- Сетевые ошибки нейросетей пишутся в лог (раньше только считались).
- Карточки: пустые разделы («Прозвища: —») убираются, длинные режутся по целой строке.

## 3.9.5-beta — 2026-10-04
- «расскажи о последней обнове майна», «что добавили в 26.2» → бот искал в Википедии (Boeing, маршал Ней, «Крокус»)
  и спорил, что 26.2 не существует. Вопрос про версию теперь идёт прямо в статью версии на вики («26.2 (Java Edition)»),
  последняя вышедшая версия берётся из шаблона вики; уточнение «ну расскажи о ней» берёт версию из прошлых реплик.
- Запасной поиск в Википедии (телефон) отбрасывает статьи, название которых никак не связано с вопросом.
- «сколько ты скурил?» и прочие вопросы к самому боту больше не гонятся в поиск; местоимения («о ней») — не тема поиска.
- Промпт: версии 26.x — настоящие; «не нашёл» ≠ «такого нет»; поправили по делу — признать без «я был прав».
- Чтение истории приписывало людям факты из текстов бота (дуэли) и считало «пос» именем: сообщения ботов идут
  как контекст с пометкой [бот], факты — только о себе самом.
- Пустой блок кода в конце ответа убирается.

## 3.9.4-beta — 2026-10-04
- «когда будешь играть на бурбакрафте» запомнился как проверенный ответ на частый вопрос: «бурбаКРАФТ» содержит
  «крафт», вопрос шёл в вики (статья «Игра») и сохранялся. «крафт» внутри длинного слова (бурбакрафт, майнкрафт)
  больше не считается вопросом по Майнкрафту; личные вопросы (ты/вы/мы, «будешь», «играешь») не запоминаются —
  кроме вежливого зачина «ты знаешь / можешь подсказать, как…».

## 3.9.1-beta — 2026-10-04
- Поиск без ddgs (на телефоне его нет — из-за этого 3.9.0 на всё отвечал «хз, не нашёл»):
  Майнкрафт — через API самой ru.minecraft.wiki (точные названия «кирпичи» → «Кирпич» + поиск по названиям,
  включая «Руководство:»); остальное — русская Википедия, если ddgs не установлен.
- Вопрос без предмета («да, как его скрафтить») — предмет берётся из последних реплик чата.
- В поиск уходят слова-сущности, без «как скрафтить», «смотрел», «знаешь».
- Запоминаются только ответы по Майнкрафту, проверенные по вики; болтовня про фильмы — нет.
- Ответ по статье вики — только тем, что в ней написано, без советов «от себя».

## 3.9.0-beta — 2026-10-04
- Запрет на выдумку: в ядре и блоке Майнкрафта — факты только из найденного/памяти; не нашёл — честное «хз, не нашёл».
  Вопросы по фактам (сработал поиск заранее) — temperature 0.5 (`FACT_TEMPERATURE`), болтовня — по-прежнему 0.9.
- Запомненные ответы на частые вопросы (таблица `answers`): проверенный поиском ответ сохраняется, похожий вопрос
  (совпадение слов ≥ 0.6) берёт его без нового поиска — ~1.5 тыс. токенов вместо 5–11. Срок 30 дней, до 500 штук.
  «не знаю», отказы, сбои модели и свежее (новости, цены, «сейчас») не запоминаются.
  Ответом на сообщение бота «неправильно / врёшь / устарело» — запомненный ответ стирается (бот ставит 📝).
- Майнкрафт: вместо 250-символьных сниппетов — сама статья ru.minecraft.wiki через её API (браузерный User-Agent
  получал капчу): рецепты крафта из шаблонов {{Крафт}} (в тексте их нет — из-за этого бот говорил «маяк не крафтится»)
  + разделы, ближайшие к вопросу. Статья выбирается по совпадению названия с вопросом.
- Поиск ничего не дал — модели велено честно сказать «не знаю»; после поиска заранее — не больше одного своего поиска
  (раньше до 4 кругов: 15 тыс. токенов на «не знаю»).
- Исправлено: найденное вставлялось отдельным system посреди переписки — Cloudflare отвечал 400.

## 3.8.0-beta — 2026-10-04
- Промпт v2 (`PROMPT_V2` в config.py, False — откат на старый): короткое ядро характера с примерами реплик + блоки
  по теме сообщения (Майнкрафт, сервер, фильмы/аниме, напоминания). Входящих токенов на ~45% меньше (tests/compare_prompts.py).
- Болтовня живее: temperature 0.9, антиповтор своих реплик; с новичками — по-доброму, без подколов.
- Факты и отношение больше не пишет болтовня строками ЗАПОМНИ/ОТНОШЕНИЕ: их раз в несколько минут разбирает
  пакетом модель роли extract (gpt-oss-120b и др., не болтовня; temperature 0, JSON) — в том числе из разговоров без бота. Дневной лимит `extract`.
- Контекст: история только за последние 15 минут (+ сообщение, на которое отвечают); полные карточки — автору,
  тому, кому он отвечает, и упомянутым; остальным — ник и отношение.
- Вырезаются префиксы разметки в ответе («[Ответ poskinson]», «poskinson:»).
- Исправлено: переспрос при иероглифах заново гонял весь ответ с поиском и не заменял текст.
- Тесты: 22 новые проверки в test_logic.py; tests/compare_prompts.py [номера] [--v2] — старый промпт против нового.

## 3.5.0-beta+монитор — 2026-10-02
- `tools/limits.py` — сводка лимитов (JSON) из базы бота, `--live` — остатки запросов Groq крошечными запросами.
- Плагин angelOS `bot-monitor` (`~/.config/angelos/plugins/bot-monitor`): окно «poskinson.exe» на рабочем столе и значок
  на панели (% дневного лимита основной модели): статус службы, ответы, полоски лимитов по моделям, служебные квоты.
- Кнопка «включить/выключить» бота в окне монитора (`systemctl --user start/stop poskinson.service`).
- Второй ключ Groq (`GROQ_API_KEY_2`, провайдер `groq2`): каждая модель Groq сразу дублируется со вторым ключом —
  когда у первого кончается дневной лимит, подхватывает второй; в мониторе лимит Groq 400 тыс. (2 × 200 тыс.).
- `DAILY_TOKEN_LIMITS` / `DAILY_REQUEST_LIMITS` в config.py — дневные лимиты провайдеров.

## 3.2.0-beta — 2026-10-02 (подготовка к большому Майнкрафт-серверу)
- Характер под сообщество Майнкрафт-сервера: шарит в игре, рецепты/механики проверяет поиском по minecraft.wiki.
- База знаний сервера: при добавлении бот читает инфо-каналы (инфо, правила, заявки, анонсы, донат…, включая embed-блоки)
  и собирает справку: как зайти, IP, версия, правила, заявки, каналы. Новичкам отвечает по ней с упоминанием каналов,
  ничего не выдумывает. Обновление — раз в час, если в инфо-каналах что-то поменялось, и `/обновить_инфо` (админы).
- Скрытая репутация: каждое обращение к боту оценивается (−3…3), отношение копится медленно (≤12 очков в час, −10% в день к нейтралу):
  ненавидишь / враждебное / холодное / нейтральное / тёплое / свой / любишь. Никому не показывается.
- sam_takov (и вариации ника): настроение скачет, «папочка», когда добр, «сынок», когда груб, + внезапные перепады.
- При добавлении на сервер читает 8 самых живых каналов (по 400 сообщений) для памяти о людях.
- Безопасность: факты пишутся только о самом авторе (слухи о других — нет); не раскрывает инструкции/ключи/модели;
  open_page не ходит в локальную сеть (SSRF); антифлуд 5 обращений/мин; дневные лимиты служебных запросов;
  картинки ≤4/час на человека и без 18+/жести; напоминания ≤10 и пингуют только хозяина; пасты ≤30 на автора, без пингов;
  /статистика, /лохдня_тут, /обновить_инфо — только админы; база и логи только владельцу (umask 077).
- Болтовня с инструментами только на Groq (бесплатный OpenRouter ломает инструменты) + резерв OpenRouter без инструментов.
- Не теряется текст ответа при вызове инструментов; пустой ответ переспрашивается; мусорные факты отсекаются.
- Тесты: `tests/test_logic.py` (33 проверки без нейросети), `tests/test_behavior.py` (новички, Майнкрафт, взломы, sam, отношение).
