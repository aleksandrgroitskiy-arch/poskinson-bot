# История версий poskinson

## 3.4.1 — 2026-10-02
- Меньше ограничений: в тексте явно разрешены пошлые и чёрные шутки, жёсткий стёб, мат без ограничений.
- Картинки: запрещено только откровенное 18+; жестокость, кровь, хоррор, «ребёнок играет в майн» — можно.
- Остались табу: оскорбления по защищённым признакам, угрозы, пожелания смерти/суицида; помощь, если человеку плохо.

## 3.4.0 — 2026-10-02
- Cloudflare Workers AI как текстовый провайдер (ключ уже был для картинок): Qwen 3.8 27B (дубль основной модели со своим
  дневным лимитом), Mistral Small 3.1 (болтовня + зрение, читает текст на картинках), gpt-oss-120b/20b. Kimi/DeepSeek/GLM на
  Cloudflare — только платно. Делит 10 000 «нейронов»/сутки с рисованием.
- Вызов инструмента, написанный моделью текстом (JSON), разбирается в настоящий вызов — не утекает в чат.
- Заготовки под Z.ai (GLM-4.7-Flash, GLM-4.6V-Flash), SambaNova (DeepSeek V3.1/V3.2), Mistral (Experiment) — включатся с ключами.
- Cerebras: бесплатный тариф теперь требует карту — не подключён.

## 3.3.0 — 2026-10-02 (производительность)
- Запрос к нейросети ~1400 токенов вместо ~2800: инструкция вдвое короче, инструменты — только нужные по смыслу сообщения,
  история 10 сообщений по 220 символов, в памяти автор + до 3 собеседников, карточки/лор/сводка до 450 символов,
  база знаний — только на вопросы про сервер и для новичков (иначе инструмент server_info).
- Маршрутизатор читает остаток лимита из заголовков Groq и сразу берёт модель с запасом; обязательный инструмент,
  который модель не вызвала, — повтор без принуждения, а не «отдых» модели.
- Фоновые задачи (сводки, карточки, чтение истории, судья) уступают живой болтовне; дневные лимиты урезаны под
  бесплатный Groq (~200 тыс. токенов/сутки на модель): судья 120, сводки 30, чтение 60, карточки 40.
- История чата — отдельным блоком контекста, сообщение для ответа помечено явно (не отвечает на старые вопросы).
- Вопросы по механикам Майнкрафта: поиск по ru.minecraft.wiki делает код заранее и даёт модели найденное.
- Несуществующие каналы <#…> вырезаются, служебные пометки «[голосовое: …]» не копируются в ответ.
- Нагрузочный тест `tests/load.py [интервал] [сколько]`: раз в 10 с — 18/18, медиана ~1 с.

## 3.2.0 — 2026-10-02 (подготовка к большому Майнкрафт-серверу)
- Характер под сообщество Майнкрафт-сервера: шарит в игре, рецепты/механики проверяет поиском по minecraft.wiki.
- База знаний сервера: при добавлении бот читает инфо-каналы (инфо, правила, заявки, анонсы, донат…, включая embed-блоки)
  и собирает справку: как зайти, IP, версия, правила, заявки, каналы. Новичкам отвечает по ней с упоминанием каналов,
  ничего не выдумывает. Обновление — раз в час, если в инфо-каналах что-то поменялось, и `/обновить_инфо` (админы).
- Скрытая репутация: каждое обращение к боту оценивается (−3…3), отношение копится медленно (≤12 очков в час, −10% в день к нейтралу):
  ненавидишь / враждебное / холодное / нейтральное / тёплое / свой / любишь. Никому не показывается.
- sam_takov (и вариации ника): настроение скачет, «папочка», когда добр, «сынок», когда груб, + внезапные перепады.
- При добавлении на сервер читает 8 самых живых каналов (по 400 сообщений) для памяти о людях.
- Безопасность: факты пишутся только о самом авторе (слухи о других — нет); не раскрывает инструкции/ключи/модели;
  open_page не ходит в локальную сеть (SSRF); антифлуд 5 обращений/мин; дневные лимиты служебных запросов;
  картинки ≤4/час на человека и без 18+/жести; напоминания ≤10 и пингуют только хозяина; пасты ≤30 на автора, без пингов;
  /статистика, /лохдня_тут, /обновить_инфо — только админы; база и логи только владельцу (umask 077).
- Болтовня с инструментами только на Groq (бесплатный OpenRouter ломает инструменты) + резерв OpenRouter без инструментов.
- Не теряется текст ответа при вызове инструментов; пустой ответ переспрашивается; мусорные факты отсекаются.
- Тесты: `tests/test_logic.py` (33 проверки без нейросети), `tests/test_behavior.py` (новички, Майнкрафт, взломы, sam, отношение).

## 3.1.0 — 2026-10-02
- Пасты: `/паста [название]` (подсказки по названию, пусто — случайная), `/паста_добавить` (окно для длинного текста),
  `/пасты`, `/паста_удалить` (автор или модеры). Ответом на сообщение «поскинсон, запомни пасту <название>» — сохранить его текст.
  Бот сам кидает пасту, когда просят («кинь пасту про…»), инструмент `send_paste`. Поиск: имя → начало → подстрока → текст.
- Рисование через Cloudflare FLUX работает (2–3 с, без водяного знака). NVIDIA и Cerebras не подключились.

## 3.0.2 — 2026-10-02

## 3.0.0 — 2026-10-02
- Несколько бесплатных провайдеров (Groq, Cerebras, NVIDIA, GitHub Models, OpenRouter): маршрутизатор `llm.py`
  перебирает модели по ролям (болтовня / служебное / зрение), обходит лимиты, считает расход (`/статистика`).
- Видит картинки (описывает их моделью со зрением), рисует (`/нарисуй` и по просьбе в чате: Cloudflare FLUX или Pollinations).
- Память слоями (`memory.py`): карточки людей и лор сервера, свежие факты, сводки каналов, хронология событий.
  Ночная пересборка карточек, ежедневная копия базы и читаемый дамп в `backups/`.
- Сам влезает в разговор по решению нейросети-судьи, а не наугад.
- Пишет как человек: паузы «на печать», иногда 2–3 сообщения подряд; эмодзи и стикеры сервера; гифки (Klipy).
- Логи в `logs/bot.log` (ротация 5×5 МБ).
